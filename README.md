# Hoja de cata — HUMA Café de Autor

Hoja de cata para catas a ciegas de 8 cafés. Una página, sin dependencias externas:
tipografías, logo y rueda de sabores van embebidos en el HTML.

Las respuestas de cada participante se guardan **solo en su propio teléfono**
(`localStorage`). No se envía nada a ningún servidor.
